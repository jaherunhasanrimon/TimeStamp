<threat_model>
ASVS Level: 1
Threat Analysis:
- Accidental Data Loss: User clicking reset button without confirmation permanently wiping all time entries and projects.
- Carbon Hotkey Conflict / Crash: Registering invalid or reserved system key combinations causing OS event handler crashes.
Mitigation:
- Enforce macOS `.alert` dialog with role: `.destructive` requiring explicit double-action user confirmation before calling `store.clearAll()`.
- Validate that registered hotkeys require at least one modifier key (`option`, `control`, or `command`), preventing single-letter key interception.
</threat_model>
