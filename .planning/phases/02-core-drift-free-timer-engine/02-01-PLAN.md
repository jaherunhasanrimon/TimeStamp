<threat_model>
ASVS Level: 1
Threat Analysis:
- Concurrency & Threading Conflicts: Timer tick updates and state mutations crossing actor boundaries could cause data races or UI crashes.
- Clock Skew / Sleep Tampering: Negative time intervals if system time is adjusted backwards during an active session.
- Resource Leaks: Unreleased `NSWorkspace` notification observers leading to memory bloat or phantom tick execution.
Mitigation:
- Enforce strict `@MainActor` on `TimerManager` and pass clean pure values to `TimeCalculator`.
- Use defensive `max(0, ...)` bounds in `TimeCalculator` to guarantee elapsed duration can never be negative.
- Implement explicit observer invalidation in `SleepWakeMonitor`.
</threat_model>
