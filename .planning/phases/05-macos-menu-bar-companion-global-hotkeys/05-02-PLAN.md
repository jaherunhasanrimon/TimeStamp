<threat_model>
ASVS Level: 1
Threat Analysis:
- Accessibility Permission Gate Block: Relying on `NSEvent.addGlobalMonitorForEvents` would fail unless user manually grants system Accessibility permissions in macOS Settings, blocking the feature.
- Key Conflict & Resource Leak: Failing to unregister Carbon hotkeys on app termination or hotkey rebinding causing dangling system event handlers.
Mitigation:
- Use Carbon `RegisterEventHotKey`, which requires zero Accessibility permissions and works globally on macOS 14+ Apple Silicon.
- Implement explicit `unregister()` and lifecycle cleanup during deinit and app termination.
</threat_model>

  <files>Sources/Core/Hotkeys/GlobalHotkeyManager.swift</files>
  <read_first>.planning/phases/05-macos-menu-bar-companion-global-hotkeys/05-RESEARCH.md, Sources/Core/Timer/TimerManager.swift</read_first>
  <action>
Create `Sources/Core/Hotkeys/GlobalHotkeyManager.swift`:
1. `import Carbon` and `import Foundation`.
2. `public final class GlobalHotkeyManager`:
   - Singleton: `public static let shared = GlobalHotkeyManager()`.
   - Private properties:
     - `hotKeyRef: EventHotKeyRef?`
     - `eventHandlerRef: EventHandlerRef?`
     - `onTrigger: (() -> Void)?`
     - `isRegistered: Bool`
   - Key code & modifier defaults (`D-08`):
     - Key code for `T`: `UInt32(kVK_ANSI_T)` (17).
     - Modifiers: `UInt32(optionKey | shiftKey)` (`⌥⇧T`).
     - HotKey ID signature: `OSType(0x544D5350)` ('TMSP'), ID: 1.
   - Methods:
     - `public func register(keyCode: UInt32 = 17, modifiers: UInt32 = UInt32(optionKey | shiftKey), onTrigger: @escaping () -> Void)`:
       - Unregisters any existing hotkey first.
       - Sets up `EventHandlerUPP` callback dispatching to `onTrigger` on `DispatchQueue.main`.
       - Calls `InstallEventHandler(GetApplicationEventTarget(), ...)` and `RegisterEventHotKey(...)`.
       - Updates `isRegistered = true`.
     - `public func unregister()`:
       - Calls `UnregisterEventHotKey(hotKeyRef)` and `RemoveEventHandler(eventHandlerRef)`.
       - Resets refs and sets `isRegistered = false`.
     - Deinit calls `unregister()`.
3. Provide a helper method:
   - `public func setupTimerToggle(timerManager: TimerManager)`:
     - Encapsulates toggle action (`D-07`):
       ```swift
       if timerManager.isRunning {
           _ = timerManager.stop()
       } else {
           timerManager.start(
               description: "",
               projectId: timerManager.retainedProjectId,
               taskId: timerManager.retainedTaskId
           )
       }
       ```
  </action>
  <acceptance_criteria>
    - `GlobalHotkeyManager` compiles and registers Carbon hotkeys.
    - Successfully unregisters on demand and deinit.
    - Encapsulates timer toggle logic starting when idle and stopping when running.
  </acceptance_criteria>
</task>
