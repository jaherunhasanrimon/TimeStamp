<threat_model>
ASVS Level: 1
Threat Analysis:
- Status Bar Layout Jitter: Dynamic font widths causing system menu bar icons to shift rapidly every second, degrading macOS user experience.
- Memory Leak & Timer Cycle: Subscribing to timer ticks inside the popover causing detached retain cycles.
Mitigation:
- Enforce `.monospacedDigit()` and fixed `HH:MM:SS` format.
- Rely on central `TimerManager.shared` environment object without creating secondary timers in the view.
</threat_model>
