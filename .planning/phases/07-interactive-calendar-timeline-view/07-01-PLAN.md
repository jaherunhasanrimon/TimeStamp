<threat_model>
ASVS Level: 1
Threat Analysis:
- Layout Calculation Crash: Division by zero when zero sub-columns or zero total column width is provided.
- Infinite Layout Loop: Circular overlap detection causing unbounded recursion.
Mitigation:
- Enforce `max(1, totalSubColumns)` in width calculation.
- Use greedy interval coloring algorithm (sweep-line interval partitioning) running in guaranteed O(N log N) time.
</threat_model>

  <files>Sources/Core/Calendar/CalendarLayoutHelper.swift</files>
  <read_first>.planning/phases/07-interactive-calendar-timeline-view/07-CONTEXT.md, Sources/Models/TimeEntry.swift, Sources/Core/Date/DateHelper.swift</read_first>
  <action>
Create `Sources/Core/Calendar/CalendarLayoutHelper.swift`:
1. Struct `PositionedBlock: Identifiable`:
   - `id: UUID`
   - `entry: TimeEntry`
   - `startMinutes: Double` (minutes from 00:00, 0 ... 1440)
   - `durationMinutes: Double`
   - `subColumnIndex: Int` (0-based column index)
   - `totalSubColumns: Int` (number of columns in this overlap group)
2. Static method `computeBlockLayouts(entries: [TimeEntry], for date: Date, calendar: Calendar = .current) -> [PositionedBlock]`:
   - Filter entries overlapping `date` (start of day to end of day).
   - If an entry started before `date`, clamp start to 00:00.
   - If an entry ends after `date` (or is active), clamp end to 24:00 (or current time).
   - Compute start minutes: `hour * 60 + minute + second / 60.0`.
   - Compute duration minutes: `effectiveDuration / 60.0`.
   - Sort entries by start minutes ascending, duration descending.
   - Sweep-line interval coloring: partition entries into non-overlapping groups and assign `subColumnIndex` and `totalSubColumns`.
   - Return positioned blocks.
  </action>
  <acceptance_criteria>
    - Correctly calculates minute offsets and duration minutes from midnight.
    - Partitions overlapping entries into non-colliding sub-columns.
    - Accurately clamps entries that span across midnight.
  </acceptance_criteria>
</task>
