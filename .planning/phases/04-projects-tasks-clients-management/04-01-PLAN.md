<threat_model>
ASVS Level: 1
Threat Analysis:
- Accidental Project / Task Data Loss: User deleting a project or task losing all past logged time entries.
- Memory & Concurrency Shadowing: `Task` model name clashes with Swift Concurrency `_Concurrency.Task`.
Mitigation:
- Enforce explicit confirmation alerts before deletion. Deleting a project cascades child tasks but preserves and unlinks time entries (`TimeEntry.projectId = nil`, `taskId = nil`). Deleting a task unlinks entries (`TimeEntry.taskId = nil`).
- In asynchronous or dispatch calls, always use explicit `_Concurrency.Task` or `MainActor.assumeIsolated`.
</threat_model>
