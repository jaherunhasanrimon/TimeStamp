<threat_model>
ASVS Level: 1
Threat Analysis:
- Accidental Project Deletion upon Client Removal: User deletes a client expecting to remove the relationship, but inadvertently loses projects or logged time.
- Filter Inconsistency: Time entries list failing to filter entries correctly when client filter is applied across multiple assigned projects.
Mitigation:
- Enforce that client deletion only resets `project.clientId = nil`, keeping all projects, tasks, and time entries intact (`D-15`).
- Client entry filtering matches any `TimeEntry` whose `projectId` corresponds to any project linked to `client.id`.
</threat_model>
