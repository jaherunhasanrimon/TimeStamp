<threat_model>
ASVS Level: 1
Threat Analysis:
- Accidental Data Deletion: User inadvertently deleting entries without confirmation causing data loss.
- Timezone & Calendar Skew: Date grouping misallocating entries across midnight boundaries when system timezone changes.
Mitigation:
- Enforce explicit macOS confirmation dialog before calling `store.deleteTimeEntry(id:)`.
- Use `Calendar.current.startOfDay(for:)` for robust date grouping.
</threat_model>
