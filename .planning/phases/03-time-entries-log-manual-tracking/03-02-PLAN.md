<threat_model>
ASVS Level: 1
Threat Analysis:
- Inverted Time Range: User entering an end time earlier than start time causing negative duration calculations.
- Orphaned Association: Associating an entry with a deleted or invalid project ID.
Mitigation:
- Enforce automatic end time adjustment when start time is shifted (`D-06`) and reject saving if `endDate < startDate`.
- Validate project existence against `store.projects` before saving.
</threat_model>

  <action>
Implement `Sources/Views/Entries/EntryEditSheet.swift`:
- Mode enum: `case edit(TimeEntry)` or `case manualLog(initialProjectId: UUID?, initialTaskId: UUID?)`.
- Environment access: `@Environment(PersistenceStore.self)`, `@Environment(TimerManager.self)`, `@Environment(\.dismiss) private var dismiss`.
- Form state:
  - `@State private var descriptionText: String`
  - `@State private var selectedProjectId: UUID?`
  - `@State private var selectedTaskId: UUID?`
  - `@State private var startDate: Date`
  - `@State private var endDate: Date`
  - `@State private var durationSeconds: TimeInterval`
- Initialization:
  - For edit: Loads values from `entry`.
  - For manualLog: Sets `startDate = Date() - 3600`, `endDate = Date()`, `durationSeconds = 3600`, pre-selects `initialProjectId`/`initialTaskId` (`D-10`, `D-11`).
- Reactive Sync (D-06, D-08):
  - When `startDate` changes: Automatically adjust `endDate = startDate + durationSeconds` to preserve duration (`D-06`).
  - When `endDate` changes: If `endDate > startDate`, update `durationSeconds = endDate.timeIntervalSince(startDate)`. If `endDate <= startDate`, adjust `endDate = startDate + 60`.
- UI Layout (460px width, ~420px height):
  - Header: Title ("Edit Time Entry" / "Log Time Entry") and subtitle.
  - Section 1: Description TextField ("What did you work on?").
  - Section 2: `ProjectTaskPickerButton` for project/task selection.
  - Section 3: DatePicker for Date, DatePicker for Start Time, DatePicker for End Time.
  - Section 4: Duration display / field formatted in `HH:MM:SS`.
  - Footer: Cancel button (dismisses) and Primary button ("Save Changes" / "Add Entry") (`D-07`, `D-12`).
- Save Action:
  - For edit: Updates `entry` properties, sets `updatedAt = Date()`, calls `store.saveTimeEntry(entry)`, and dismisses.
  - For manualLog: Creates new `TimeEntry(entryDescription: ..., startDate: startDate, endDate: endDate, accumulatedDuration: durationSeconds, isPaused: false, projectId: selectedProjectId, taskId: selectedTaskId)`, calls `store.saveTimeEntry(newEntry)`, and dismisses.
  </action>
