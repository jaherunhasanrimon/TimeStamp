<threat_model>
ASVS Level: 1
Threat Analysis:
- Division-by-Zero in Progress Ring: User setting target to 0 causing NaN/Infinity rendering freeze.
- Timezone Calendar Skew: Weekly bar chart shifting days when user travels across timezones or DST transitions.
Mitigation:
- Enforce `max(0.1, targetHours)` in all percentage and progress ring computations.
- Use `Calendar.current` with date intervals anchored to `calendar.date(from: calendar.dateComponents([.yearForWeekOfYear, .weekOfYear], from: now))` for Monday–Sunday grouping.
</threat_model>

2. State: `@AppStorage("dailyTargetHours") private var targetHours: Double = 8.0` (`D-02`).
3. Metrics calculation:
   - Today's start of day: `DateHelper.startOfDay(for: Date())`.
   - Today's entries: `store.timeEntries.filter { $0.startDate >= todayStart }`.
   - Today's completed duration sum + active entry duration (if started today).
   - Target seconds: `targetHours * 3600`.
   - Progress ratio: `min(1.0, todayDuration / max(1.0, targetSeconds))`.
   - Percentage: `Int(round((todayDuration / max(1.0, targetSeconds)) * 100))`.
   - Is goal reached: `todayDuration >= targetSeconds` (`D-04`).
4. UI Structure (`D-01`):
   - Circular Progress Ring:
     - 140px diameter, 12px stroke line.
     - Background track: `Color.secondary.opacity(0.15)`.
     - Foreground arc: `Circle().trim(from: 0, to: progressRatio)`.
     - Color: `AppColors.success` if `isGoalReached`, else `AppColors.brandAccent` (`D-04`).
     - Center text: Large duration (`AppTypography.displayTicker`), percentage label below.
   - Side Info Column:
     - Title "Today's Progress".
     - Daily target dropdown picker menu:
       - Presets: 4h, 6h, 7.5h, 8h, or custom stepper.
     - Overtime badge if `isGoalReached`: `+Xm over goal` in green pill (`D-04`).
     - Remaining time label if `< 100%`: "Remaining: Xh Ym".
  </action>
