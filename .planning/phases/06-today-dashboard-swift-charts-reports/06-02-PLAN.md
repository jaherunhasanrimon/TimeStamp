<threat_model>
ASVS Level: 1
Threat Analysis:
- CSV Injection: Special characters (commas, newlines, quotation marks) in project or entry descriptions corrupting CSV export structure.
- App Hang on Large Export: Serializing thousands of entries freezing the main UI thread.
Mitigation:
- Sanitize and wrap all string fields in double quotes, escaping internal quotes (`""`) conforming to RFC 4180 CSV standard.
- Perform serialization synchronously in-memory (lightweight for desktop scale < 50MB) and present file save panel smoothly.
</threat_model>

     - Configures `NSSavePanel`:
       - `nameFieldStringValue = defaultFilename`
       - `allowedContentTypes = [fileExtension == "csv" ? .commaSeparatedText : .json]`
       - Runs asynchronously on `NSApplication.shared.keyWindow` or synchronously via `panel.runModal()`.
       - Writes `data` to `panel.url`.
